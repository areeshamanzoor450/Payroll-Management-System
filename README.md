# Payroll Management System

A Python-based Payroll Management System designed to simplify employee management, attendance tracking, salary processing, and administrative operations.

## Project Overview

The system provides an organized solution for managing employee records, monitoring attendance, processing payroll, and generating reports. It follows a structured architecture and applies software design patterns to improve code organization and maintainability.

## Features

- Employee Management
- Attendance Tracking
- Payroll and Salary Management
- Admin Configuration
- User Management
- Admin Audit Logs
- Payroll Reports
- Database Integration
- Input Validation

## Technologies Used

- **Programming Language:** Python
- **Database:** SQL
- **Architecture:** Layered Architecture
- **Design Patterns:** Factory, Repository, and Strategy

## Design Patterns

- **Factory Pattern:** Organizes object creation.
- **Repository Pattern:** Separates data access logic from business logic.
- **Strategy Pattern:** Supports flexible and interchangeable business logic.

## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/areeshamanzoor450/Payroll-Management-System.git
```

**2. Navigate to the project directory**

```bash
cd Payroll-Management-System
```

**3. Install the required dependencies** according to the project configuration.

**4. Configure the database connection.**

**5. Run the application**

```bash
python payroll/main.py
```
